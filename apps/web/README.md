# @gennode/web

Gennode landing page, live at **[gennode.org](https://gennode.org)** — **Vite + React + TypeScript + React Three Fiber + Tailwind**.

```bash
npm install
npm run dev        # http://localhost:5174
npm run typecheck
npm run build      # -> dist/
```

- 3D models (optimized GLB) live in `public/models/`.
- `src/components/Intro.tsx` — opening animation · `DNA.tsx` — hero · `Model3D.tsx` — reusable model viewer.
