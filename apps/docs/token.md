# $GENE token

`$GENE` is the utility token that fuels the Gennode network.

- **Chain:** Base
- **Launch:** fair launch via Bankr (Clanker v4)
- **Supply:** 100,000,000,000 (fixed, non-mintable)

## Utility
- **Access** — premium features (longer context, doctor mode, priority)
- **Governance** — vote on parameters, models and treasury
- **Rewards** — funds the community airdrop today, and node-operator pay when the network goes live

## Where rewards come from
The network is designed to be **self-funded**. Trading fees (from the token's liquidity) and product revenue flow back into buybacks, the community airdrop, and — in the node phase — operators who contribute real compute.

| Allocation | Share |
| --- | --- |
| Public liquidity (fair launch) | **100%** |
| Team / insiders | 0% |
| Dev buy / pre-mine | 0% |

A **100% fair launch**: no team allocation, no pre-mine, no insider buy — every token hits the open market. Treasury, the airdrop and node rewards are funded **entirely by trading fees**, not by a token allocation.
