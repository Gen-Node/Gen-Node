# Node requirements

Running a Gennode node is light to start (uptime + benchmark) and scales with what you choose to contribute.

## Minimum
- **OS:** macOS 12+, Windows 10+, or Linux (x64 / arm64)
- **CPU:** any modern 4-core
- **RAM:** 8 GB
- **Disk:** 10 GB free (more disk = more storage rewards)
- **Network:** stable broadband
- **Wallet:** any EVM wallet (your node identity)

## Recommended (earn more)
- **GPU:** NVIDIA (CUDA) 8 GB+ VRAM, AMD, or Apple Silicon — the more capable, the more compute jobs you can earn from
- **Disk:** 100 GB+ to serve more of the [data layer](/data-layer)
- **Uptime:** the longer you stay online, the more points

## What a node contributes
- **Compute (GPU)** — run jobs: DNA & genome analysis, protein folding, disease research
- **Storage (disk)** — hold & serve encrypted data shards
- **Uptime** — availability points

> v1 is intentionally light (uptime + benchmark). Heavier compute jobs are **opt-in** as they roll out, and the app lets you cap how much CPU/GPU/disk it uses.
