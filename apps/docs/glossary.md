# Glossary

- **Node** — the Gennode app running on your machine, contributing GPU + storage to the network.
- **Coordinator** — matches jobs to capable nodes, verifies results, and tracks points.
- **Job** — a unit of work (e.g. a DNA analysis, a protein fold, an inference request).
- **Points** — earned for uptime, capacity and completed jobs; convert to `$GENNODE` in the airdrop.
- **Data layer** — the torrent-like, encrypted storage spread across nodes.
- **Content addressing** — identifying data by its hash (tamper-proof, de-duplicated).
- **DHT** (Distributed Hash Table) — a decentralized index mapping content → which nodes hold it.
- **Erasure coding** — redundancy (e.g. Reed–Solomon) that keeps data durable if nodes drop offline.
- **Shard** — an encrypted piece of a file stored on a node.
- **Anti-sybil** — measures (wallet identity, device fingerprint, benchmark) that stop fake-node farming.
- **Confidential computing (TEE)** — hardware that lets nodes compute on data without seeing it.
- **Fair launch** — 100% of supply to the open market; no team, pre-mine or presale.
- **$GENNODE** — the network's utility token on Base, launched via Bankr.
