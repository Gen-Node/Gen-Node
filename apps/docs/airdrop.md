# Points & airdrop

Run a node, earn **points** → convert to **`$GENNODE`** in the airdrop.

## How to earn points
- **Run a node** — points = `uptime × capacity` (the main way)
- **Complete jobs** (as the network goes live) — real compute will earn more
- **Referrals** and **community tasks** (planned — Phase 3 of the [Roadmap](/roadmap))

## Anti-sybil
Today, fairness comes from **wallet linking**, a **CPU benchmark** that proves a node runs on real hardware, and a **device fingerprint** enforcing one device = one node = one wallet. Cluster analysis is **planned** to further protect rewards for genuine operators.

## Conversion
No tokens are pre-allocated for the airdrop. Accrued **fees buy `$GENNODE` on the market** and distribute it to points-holders via a Merkle claim. The snapshot and details are published **before** launch through official channels.
