# FAQ

### What is Gennode?
A private, torrent-like decentralized node network for heavy bio & health compute. Run a node on your computer, contribute idle GPU + storage, and earn `$GENNODE`. *Genes meet nodes.*

### What does a node actually do?
It stays online and — as the network rolls out — runs jobs the network dispatches: DNA & genome analysis, protein folding, genomics, drug discovery and disease research.

### What do I need?
A computer (Mac / Windows / Linux), a wallet, and internet. A GPU is recommended but not required. Run the headless CLI today, or use the desktop app once it ships.

### How do I earn?
Points = `uptime × capacity`. Completed jobs add points as real compute goes live. Points convert to `$GENNODE` in the airdrop.

### Is it like io.net or Nosana?
Same idea (run a node, earn) — but focused on one vertical: **heavy bio & health compute**, with a private, torrent-like data layer for sensitive datasets.

### What is $GENNODE?
The network's planned utility token on **Base** — a 100% fair launch via Bankr. It is **not launched yet**. See [Token](/token).

### Can I run it now?
Yes — the headless CLI: `npx @gennode/node`, or download the desktop app (early access) from [GitHub Releases](https://github.com/Gen-Node/Gen-Node/releases).
