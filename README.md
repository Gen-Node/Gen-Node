# Gennode

> Private health AI, built for one vertical: **bio**. Powered today by Venice; tomorrow by a decentralized network of community GPU nodes.

**Status:** Phase 1 — Health AI (beta) + landing page. Node network = future (see [PLAN.md](./PLAN.md)).

## Repo
```
gennode/
├─ PLAN.md            # master plan (vision, tokenomics, roadmap, grants)
└─ apps/
   └─ web/            # 3D landing page — Vite + React + React Three Fiber + Tailwind
```

## Run the website
```bash
cd apps/web
npm install
npm run dev      # http://localhost:5174
npm run build    # production build → dist/
```
