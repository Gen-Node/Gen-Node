# Security Policy

Gennode is **early-access** software under active development. We take security reports seriously and appreciate responsible disclosure.

## Reporting a vulnerability

Please report vulnerabilities **privately** — do **not** open a public issue.

- **Email:** [dev@gennode.org](mailto:dev@gennode.org)
- **GitHub:** private vulnerability reporting — [Security → Report a vulnerability](https://github.com/Gen-Node/Gen-Node/security/advisories/new) on this repository.

We aim to acknowledge reports within 72 hours.

## Scope

- The Gennode sites: [gennode.org](https://gennode.org), [docs.gennode.org](https://docs.gennode.org), [app.gennode.org](https://app.gennode.org)
- Coordinator API and dashboard (`apps/gateway`)
- Desktop node app (`apps/desktop`) and the published node CLI (`packages/node`)
- **At token launch:** smart contracts — third-party audits and a bug bounty will be announced before mainnet deployment.

## Guidelines

- Do not include secrets, private keys, or personal data in any report.
- Do not access, modify, or destroy data that is not your own while researching.
- Give us reasonable time to remediate before any public disclosure.
